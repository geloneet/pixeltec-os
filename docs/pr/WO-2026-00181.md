## 2. Diseño

### 2.1 Backend de gestión (`src/lib/whatsapp/management.ts` + rutas)

- Nuevo módulo `src/lib/whatsapp/management.ts` con el **mismo patrón** de `sender.ts` (env `WHATSAPP_ACCESS_TOKEN`, `WHATSAPP_API_VERSION`, `WHATSAPP_PHONE_NUMBER_ID`; nueva env **`WHATSAPP_BUSINESS_ACCOUNT_ID`**; timeout; `redirect: "manual"`; logs con ids enmascarados `***`+4; nunca el token en logs ni respuestas).
  - `getPhoneNumberInfo()` → `GET /{phone_number_id}?fields=display_phone_number,verified_name,quality_rating,name_status,code_verification_status,messaging_limit_tier,platform_type`
  - `getBusinessProfile()` → `GET /{phone_number_id}/whatsapp_business_profile?fields=about,address,description,email,profile_picture_url,websites,vertical`
  - `listMessageTemplates()` → `GET /{waba_id}/message_templates?fields=id,name,language,status,category,components,rejected_reason,quality_score&limit=50`
  - `createMessageTemplate(input)` → `POST /{waba_id}/message_templates` con builder **puro** `buildTemplateCreatePayload(input)` en `src/lib/whatsapp/template-builder.ts` (validación: `name` `^[a-z0-9_]{1,512}$`, `language` ∈ {es_MX, es, en_US, en}, `category` ∈ {UTILITY, MARKETING} (AUTHENTICATION excluida a propósito), `body` ≤ 1024 con variables `{{n}}` correlativas desde 1 y `example.body_text` obligatorio cuando hay variables, `footer` opcional ≤ 60).
  - Estado «no configurado» explícito: si falta token/ids ⇒ `{ configured: false, reason }` (nunca throw ni 500). Errores Graph ⇒ mensaje saneado (código Meta + título), sin filtrar el cuerpo completo.
- Rutas nuevas bajo `/api/whatsapp-inbox/` (guard `requireWhatsAppReviewAccess`, `runtime = "nodejs"`, `dynamic = "force-dynamic"`):
  - `GET /account` → `{ configured, phone, profile }`
  - `GET /templates` → `{ configured, templates[] }`
  - `POST /templates` → crea; 400 con detalle de validación del builder; 502 saneado si Meta rechaza.
- `src/lib/routes/reviewer-access.ts`: allowlist +3 reglas (`GET /account`, `GET /templates`, `POST /templates`) → 16; actualizar tests de contrato (`reviewer-access.test.ts`, `reviewer-routes.access.test.ts`, `reviewer-access.contract.test.ts`). **`middleware.ts` y `auth-guards.ts` no se tocan.**
- `.env.example`: documentar `WHATSAPP_BUSINESS_ACCOUNT_ID`.
